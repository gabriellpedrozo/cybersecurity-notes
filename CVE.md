# CVE — Common Vulnerabilities and Exposures

## O que é?

CVE é um sistema utilizado para identificar e registrar vulnerabilidades de segurança conhecidas em softwares, sistemas e dispositivos. Cada vulnerabilidade recebe um código único no formato `CVE-ANO-NÚMERO`, como `CVE-2024-12345`.

## CVE

O código CVE facilita a identificação e pesquisa de uma vulnerabilidade específica. A partir dele, é possível encontrar informações como descrição da falha, versões afetadas, referências e possíveis correções.

## CVSS

O **CVSS (Common Vulnerability Scoring System)** é utilizado para avaliar a gravidade de uma vulnerabilidade. A pontuação normalmente varia de **0 a 10**, indicando o nível de impacto e risco da falha.

De forma geral:

- **0.0:** Nenhum
- **0.1 – 3.9:** Baixo
- **4.0 – 6.9:** Médio
- **7.0 – 8.9:** Alto
- **9.0 – 10.0:** Crítico

## Importância para Pentest

Durante um pentest, consultar CVEs pode ajudar a identificar vulnerabilidades conhecidas em versões específicas de softwares e tecnologias encontradas durante o reconhecimento.

## O que eu aprendi

Aprendi que o **CVE identifica uma vulnerabilidade**, enquanto o **CVSS ajuda a medir sua gravidade**. Também entendi que esses códigos são importantes para pesquisar vulnerabilidades conhecidas e avaliar quais delas podem representar maior risco para um sistema.
